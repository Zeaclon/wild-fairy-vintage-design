# Wild Fairy Vintage

An editorial landing experience for Wild Fairy Vintage.

## Stack

- React + TypeScript
- Vite
- Framer Motion
- CSS art direction

## Run

```bash
npm install
npm run dev
```

## Content note

The site deliberately does not invent product names, reviews, sales numbers, testimonials, or brand claims. The shopping CTA points to the supplied Wild Fairy Vintage Depop shop and the social CTA points to the supplied Instagram account.

The current visual studies use real editorial photography from Unsplash as temporary art direction. Replace those URLs with Wild Fairy Vintage's own photography before presenting this as the finished client site.
